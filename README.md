# Touhou-Meme-Project
The Touhou Meme Project is a THCRAP run patch that will memeify (soon to be) all Team Shanghai Alice Windows games. (Touhou 6 - 20)

- Reimu Blue, Green, and Yellow dialogue routes changed.
  - Reimu "Snow Blossom" and "Imperishable Moon" Extra dialogue changed.
- All enemy titles, bgm titles, and stage logos changed.
- All spellcard names changed.
- Title screen changed.
